# rakitin examples

Every folder here was **generated by the rakitin CLI itself** using the exact
commands listed below - nothing was hand-edited afterwards. They demonstrate
the three integration tiers.

| Example | Tier | Generated with |
|---------|------|----------------|
| `basic-express` | 🟢 Basic (zero extra deps) | module none-orm + middleware + integrate |
| `intermediate-prisma-modular` | 🟡 Intermediate | Prisma module + config + integrate |
| `advanced-fullstack-api` | 🔴 Advanced recipes | auth + swagger + docker |

> `node_modules/` and lockfiles were stripped after generation to keep the
> repo light. Run `npm install` inside any folder to wire dependencies back.

## basic-express

```bash
rakitin add module tasks --arch modular --orm none --yes
rakitin add middleware logger --yes
rakitin integrate
```

Result: pure-Express CRUD scaffold that drops into ANY existing Express app -
no additional runtime dependencies required. The main router is already
marker-managed (`app/routes/index.js`).

## intermediate-prisma-modular

Prerequisite: a minimal `prisma/schema.prisma` existed before generating
(client + sqlite datasource blocks only).

```bash
rakitin add module products --arch modular --orm prisma --no-install --yes
rakitin add config database
rakitin integrate
```

Note the interesting bits after generation:

* `prisma/schema.prisma` now contains the appended `model Products` block,
  so the Prisma CLI actually consumes it.
* `app/shared/config/db.js` is the generated Prisma client singleton.
* Service/controller require chains use consistent kebab-case file names.

## advanced-fullstack-api

```bash
rakitin recipe auth --arch simple --pm npm
rakitin recipe swagger
rakitin recipe docker
```

Result: JWT middleware + user module (in-memory store) + Joi register/login
validator, OpenAPI 3 spec (`app/docs/openapi.json`) wired through
`mountSwagger(app)`, plus Dockerfile/compose/.dockerignore.

Try it:

```bash
npm install
JWT_SECRET=dev node app/server.js   # if you add a server entrypoint
docker build -t my-api .
```

## Regenerating any example from scratch

Delete the target folder, recreate an empty npm project, then re-run the same
commands above against your installed version of `rakitin`. Idempotency means
re-running a command will never clobber files you edited by hand.
