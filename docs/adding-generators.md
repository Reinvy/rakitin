# 🛠️ Cara Menambah Generator Baru di rakitin

## 🇮🇩 Bahasa Indonesia

### Pendahuluan

Dokumen ini menjelaskan cara menambah generator baru ke **rakitin CLI**. Generator adalah komponen yang bertanggung jawab untuk membuat file atau struktur direktori tertentu secara otomatis.

### Struktur Generator

Setiap generator di rakitin memiliki struktur yang serupa:

```
lib/generator/[generator-name]/
├── [generator-name].js    # File utama generator
└── ...                    # File pendukung jika diperlukan
```

### Langkah-langkah Menambah Generator Baru

#### 1. Membuat Struktur Direktori

Pertama, buat direktori baru untuk generator Anda:

```bash
mkdir -p lib/generator/[generator-name]
```

Ganti `[generator-name]` dengan nama generator yang ingin Anda buat (misalnya: `controller`, `service`, `model`).

#### 2. Membuat File Generator Utama

Buat file utama generator di dalam direktori yang baru dibuat:

```bash
touch lib/generator/[generator-name]/[generator-name].js
```

#### 3. Implementasi Generator

Berikut adalah template dasar untuk implementasi generator:

```javascript
const fs = require("fs");
const path = require("path");
const inquirer = require("inquirer");
const { basePath, modulesPath, sharedPath } = require("../../constants");
const { ensureDir, toPascalCase, toCamelCase, toKebabCase } = require("../../utils");

/**
 * Generator untuk [generator-description]
 */
async function generate[GeneratorName]() {
  try {
    // Kumpulkan input dari pengguna
    const { [inputName] } = await inquirer.default.prompt([
      {
        type: "input",
        name: "[inputName]",
        message: "Masukkan [input-description]:",
        validate: (input) => {
          if (!input) {
            return "[input-name] tidak boleh kosong";
          }
          return true;
        }
      },
      // Tambahkan prompt lain jika diperlukan
    ]);

    // Proses input
    const pascalName = toPascalCase([inputName]);
    const camelName = toCamelCase([inputName]);
    const kebabName = toKebabCase([inputName]);

    // Tentukan path output
    const outputPath = path.join([base-path], kebabName);
    
    // Buat direktori jika diperlukan
    ensureDir(outputPath);

    // Siapkan konten file
    const content = `// Generated by rakitin
// [description]

${[file-content]}
`;

    // Tulis file
    const filePath = path.join(outputPath, `${kebabName}.[extension]`);
    fs.writeFileSync(filePath, content, "utf8");

    console.log(`✅ [generator-name] berhasil dibuat di ${filePath}`);
  } catch (error) {
    console.error(`❌ Gagal membuat [generator-name]:`, error.message);
  }
}

module.exports = generate[GeneratorName];
```

#### 4. Mendaftarkan Generator di Index

Tambahkan generator baru ke file `index.js`:

```javascript
// Tambahkan import di bagian atas
const generate[GeneratorName] = require("./lib/generator/[generator-name]/[generator-name]");

// Tambahkan case di fungsi main()
switch (feature) {
  // ... case yang sudah ada
  case "[Generator Name]":
    return generate[GeneratorName]();
  default:
    console.log("Batal.");
}
```

#### 5. Menambahkan ke Prompt

Tambahkan generator baru ke daftar pilihan di `lib/prompt.js`:

```javascript
const mainPrompt = () =>
  inquirer.default.prompt([
    {
      type: "list",
      name: "feature",
      message: "Apa yang ingin Anda generate?",
      choices: [
        "Module",
        "Middleware",
        "Util",
        "Config",
        "Router Integration",
        "[Generator Name]", // Tambahkan ini
      ],
    },
  ]);
```

## 🇬🇧 English

### Introduction

This document explains how to add a new generator to **rakitin CLI**. A generator is a component responsible for automatically creating specific files or directory structures.

### Generator Structure

Each generator in rakitin has a similar structure:

```
lib/generator/[generator-name]/
├── [generator-name].js    # Main generator file
└── ...                    # Supporting files if needed
```

### Steps to Add a New Generator

#### 1. Create Directory Structure

First, create a new directory for your generator:

```bash
mkdir -p lib/generator/[generator-name]
```

Replace `[generator-name]` with the name of the generator you want to create (e.g., `controller`, `service`, `model`).

#### 2. Create Main Generator File

Create the main generator file inside the newly created directory:

```bash
touch lib/generator/[generator-name]/[generator-name].js
```

#### 3. Implement the Generator

Here's a basic template for generator implementation:

```javascript
const fs = require("fs");
const path = require("path");
const inquirer = require("inquirer");
const { basePath, modulesPath, sharedPath } = require("../../constants");
const { ensureDir, toPascalCase, toCamelCase, toKebabCase } = require("../../utils");

/**
 * Generator for [generator-description]
 */
async function generate[GeneratorName]() {
  try {
    // Collect user input
    const { [inputName] } = await inquirer.default.prompt([
      {
        type: "input",
        name: "[inputName]",
        message: "Enter [input-description]:",
        validate: (input) => {
          if (!input) {
            return "[input-name] cannot be empty";
          }
          return true;
        }
      },
      // Add other prompts if needed
    ]);

    // Process input
    const pascalName = toPascalCase([inputName]);
    const camelName = toCamelCase([inputName]);
    const kebabName = toKebabCase([inputName]);

    // Determine output path
    const outputPath = path.join([base-path], kebabName);
    
    // Create directory if needed
    ensureDir(outputPath);

    // Prepare file content
    const content = `// Generated by rakitin
// [description]

${[file-content]}
`;

    // Write file
    const filePath = path.join(outputPath, `${kebabName}.[extension]`);
    fs.writeFileSync(filePath, content, "utf8");

    console.log(`✅ [generator-name] successfully created at ${filePath}`);
  } catch (error) {
    console.error(`❌ Failed to create [generator-name]:`, error.message);
  }
}

module.exports = generate[GeneratorName];
```

Add the new generator to the `index.js` file:

### Best Practices for Generators

#### 1. Input Validation

Always validate user input:

```javascript
validate: (input) => {
  if (!input) {
    return "Input cannot be empty";
  }
  if (!/^[a-zA-Z]+$/.test(input)) {
    return "Input can only contain letters";
  }
  return true;
}
```

#### 2. Error Handling

Use try-catch to handle errors:

```javascript
try {
  // Generator logic
} catch (error) {
  console.error(`❌ Failed to create generator:`, error.message);
}
```

#### 3. Logging

Provide clear feedback to the user:

```javascript
console.log(`✅ Generator successfully created at ${filePath}`);
```

#### 4. Comments

Use JSDoc for function documentation:


#### 5. Naming Conventions

Follow consistent naming conventions:

- Function names: `camelCase`
- Class names: `PascalCase`
- Variable names: `camelCase`
